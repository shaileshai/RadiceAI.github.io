05 — Trust

When someone entitled to ask, asks.

A regulator, a client, a partner on a Sunday night. What you can hold us to, written down so it can be checked against what actually happens.

The undertakings

Six lines, no asterisks.

Every one of these is a thing a client can hold us to in front of somebody else. If a line here ever stops being true, this page changes the same day.

Data

Client files stay inside the boundary. If a sample is needed to write an honest brief, it is named, time-boxed, and destroyed on the last day — in writing.

Runtime

Their machines, or a European tenant in their name. Never a shared cloud holding many firms' material at once.

Signature

A human signs the work. The kit drafts and cites; it does not certify, advise, or approve.

Citation

Every answer points at the file and the page it came from, or it declines to answer.

Exit

A runbook so the practice can keep the kit without us. Leaving should cost nothing but a conversation.

Claims

No invented metrics, no logos we have not earned, no case studies from firms that did not agree to be named.

This site

Built the same way.

A company that sells a boundary should not be running three analytics vendors on its own marketing pages. Open your browser's network panel on any page of this site: every request it makes is listed below, and there is nothing else.

One of these is uncomfortable and we have left it in.

Static pages, no trackers

Eleven HTML documents and one script bundle. No tag manager, no advertising pixel, no chat widget, no embedded video.

Fonts served from this domain

The two typefaces are files here, not requests to Google. Loading a font from a CDN discloses a reader's IP address to a foreign server before they have agreed to anything, which is the whole argument in miniature.

No forms, no form vendor

The briefing page composes a message in your own mail client. Nothing you type reaches us until you press send yourself, and it never passes through anyone else.

No cookies

None, at present. If we ever add a page counter it will be self-hosted, cookieless, and off until you accept — and declining will leave nothing behind.

Served from the United States

These pages are on GitHub Pages, which is American. No client file or model touches it, but it is a fair thing to hold against us and we would rather you heard it here. The full answer.

Checked, not asserted

The build refuses to publish if any page requests anything off this domain, if a link points at a section that does not exist, or if a claim on this page stops matching the code.
